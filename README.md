# AI-Based Financial Transaction Analysis & Automated Journal Entry System

## Project Overview
This project is an AI-powered accounting system developed using Python and Streamlit. It automatically analyzes financial transactions and generates journal entries with debit and credit accounts.

## Features
- Automated Journal Entry Generation
- Compound Purchase Transactions
- Compound Income Transactions
- Compound Expense Transactions
- Dashboard Analytics
- Excel Export System
- Income vs Expense Analysis
- User-wise Transaction Records

## Technologies Used
- Python
- Streamlit
- Pandas
- OpenPyXL
- Regex

## How to Run

```bash
pip install -r requirements.txt
streamlit run app.py
